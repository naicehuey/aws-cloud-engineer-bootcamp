# New AWS Concepts

## AWS Region

A Region is a geographic location where AWS operates multiple data centers.

## Availability Zone (AZ)

Availability Zones are isolated data centers within a Region that provide redundancy and improve service availability if one location experiences a failure.

## AWS Credits

AWS Credits help pay for eligible AWS services. Monitoring them regularly is important to avoid unexpected charges.

# Mistakes to Avoid

- Creating resources without first checking the selected AWS Region.
- Ignoring the Billing Dashboard and AWS Credits.
- Assuming every AWS service is available in every Region.
- Rushing through the Console without learning where important settings are located.
