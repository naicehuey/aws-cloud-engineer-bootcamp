**Date:** July 29, 2026

## Goal

Get comfortable with the AWS Management Console before creating any resources, so I know where things are when I start building.

## Work completed

1. Logged in and explored the Console Home page.
2. Used the search bar to find services.
3. Pinned the services I expect to use often.
4. Changed the AWS Region and saw how the services shown can change.
5. Read about Regions and Availability Zones.
6. Opened the Billing and Cost Management dashboard.
7. Checked my AWS Credits.

## What I learned

* The Console is the central place to manage AWS services.
* A Region is a geographic location, and it contains several Availability Zones.
* Billing and credits are worth checking before creating anything.

## Issue and lesson

The Console looked overwhelming at first, and I mixed up Regions and Availability Zones. I slowed down, explored without creating anything, and reread the concepts until the difference made sense: a Region contains several AZs.

Lesson: take time to learn the layout first. It saves mistakes later.

## Mistakes to avoid (for my future projects)

* Creating resources without checking the selected Region.
* Ignoring the Billing dashboard and AWS Credits.
* Assuming every service is available in every Region.
* Rushing through the Console without learning where settings are.
