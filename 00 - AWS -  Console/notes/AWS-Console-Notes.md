# AWS Console Notes

## AWS Region

A Region is a geographic location where AWS operates multiple Availability Zones.

Examples:

- us-east-1 (N. Virginia)
- us-east-2 (Ohio)
- eu-west-2 (London)

---

## Availability Zone

Availability Zones are isolated data centers inside a Region.

Example:

US East (N. Virginia)

├── us-east-1a

├── us-east-1b

├── us-east-1c
