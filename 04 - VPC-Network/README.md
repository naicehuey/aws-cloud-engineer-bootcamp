# 04 - VPC Network

## Overview

This project demonstrates my practical introduction to Amazon VPC networking.

The purpose of this lab was to understand how a Virtual Private Cloud (VPC), subnet, Internet Gateway, route table, and routes work together to create network connectivity in AWS.

This project was completed as part of my AWS Cloud Engineer practical learning journey.

---

## Objectives

The objectives of this lab were to:

- Understand the purpose of an Amazon VPC.
- Create a custom VPC.
- Configure an IPv4 CIDR block.
- Create a subnet inside the VPC.
- Understand Availability Zones.
- Create an Internet Gateway.
- Attach an Internet Gateway to a VPC.
- Create a route table.
- Create a default route to the Internet Gateway.
- Associate the route table with a subnet.
- Understand the basic relationship between a VPC, subnet, route table, and Internet Gateway.

---

## AWS Service Used

### Amazon VPC

Amazon Virtual Private Cloud (VPC) allows AWS resources to run inside a logically isolated virtual network that can be configured according to the application's networking requirements.

In this project, I created a custom VPC and configured a subnet and basic internet routing.
