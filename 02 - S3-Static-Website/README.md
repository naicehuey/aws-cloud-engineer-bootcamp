# 02 - S3 Static Website Hosting

## Overview

This project demonstrates how Amazon S3 can be used to host a static website.

I built a simple personal Cloud Engineer website using HTML, CSS and JavaScript, uploaded the website files to an Amazon S3 bucket, configured static website hosting, and tested the website and custom error page.

This project was completed as part of my AWS Cloud Engineer practical learning journey.

---

## Objective

The objectives of this project were to:

- Understand how Amazon S3 stores website files as objects.
- Upload a static website to an S3 bucket.
- Configure S3 static website hosting.
- Configure an index document.
- Configure a custom error document.
- Understand S3 website endpoints.
- Configure bucket permissions for website access.
- Test the website from a browser.
- Test the custom error page.
- Document the deployment process.

---

## AWS Service Used

### Amazon S3

Amazon Simple Storage Service (S3) is an object storage service used to store and retrieve data.

In this project, S3 is used to store and serve the files required for a static website.
