# Amazon RDS Multi-AZ PostgreSQL — Study Notes

## 1. Core Architecture

```text
Internet / User
       |
       v
EC2 Application Server
       |
       | TCP 5432
       v
RDS Security Group
       |
       v
RDS PostgreSQL
   /          \
Primary      Standby
AZ 1          AZ 2
```

Core idea:

> **The EC2 application server talks to a private RDS PostgreSQL database through TCP port 5432, while the RDS security group allows that traffic only from the EC2 security group.**

# 2. Service Roles

| Service / Component | Role |
|---|---|
| EC2 | Application/jump server |
| EC2 Security Group | Controls access to EC2 |
| RDS PostgreSQL | Managed relational database |
| RDS Security Group | Controls PostgreSQL network access |
| Multi-AZ | Maintains a standby database in another AZ |
| RDS Snapshot | Provides a database backup/recovery point |
| VPC | Provides the network boundary |

# 3. Most Important Security Relationship

```text
ec2-app-sg
      |
      | allowed source
      v
rds-postgres-sg
      |
      | TCP 5432
      v
RDS PostgreSQL
```

The database rule should not be:

```text
PostgreSQL
5432
0.0.0.0/0
```

The intended rule is:

```text
PostgreSQL
5432
Source: ec2-app-sg
```

# 4. Why Use a Security Group as the Source?

Instead of allowing a broad IP range, the database allows traffic from the intended application security group.

Mental model:

```text
Who are you?
     ↓
EC2 Security Group
     ↓
Are you allowed?
     ↓
RDS Security Group
     ↓
TCP 5432
```

# 5. PostgreSQL Port

PostgreSQL uses:

```text
TCP 5432
```

Therefore:

```text
Application → PostgreSQL
```

requires access to:

```text
TCP/5432
```

The RDS security group controls inbound PostgreSQL access.

# 6. RDS Endpoint

RDS provides a DNS endpoint similar to:

```text
huey-postgres-db.xxxxxxxxxxxx.us-east-1.rds.amazonaws.com
```

Connect with:

```bash
psql -h YOUR-RDS-ENDPOINT-HERE -U postgres -d appdb
```

Use the endpoint generated by your own RDS database.

# 7. What `psql` Means

`psql` is the PostgreSQL command-line client.

```bash
psql -h endpoint -U postgres -d appdb
```

Breakdown:

```text
psql
 |
 +-- -h → database host
 |
 +-- -U → database user
 |
 +-- -d → database name
```

# 12. Multi-AZ Mental Model

```text
                 RDS PostgreSQL
                       |
          +------------+------------+
          |                         |
          v                         v
       Primary                   Standby
        AZ 1                      AZ 2
          \                       /
           \__ Synchronous ______/
               replication
```

The purpose is increased database availability.

The application uses the RDS endpoint rather than selecting the standby manually.

# 13. Multi-AZ vs Snapshot

These are different concepts.

### Multi-AZ

```text
Availability
Failover
Infrastructure redundancy
```

### Snapshot

```text
Backup
Recovery
Database recovery point
```

Memory:

> **Multi-AZ helps keep the database service available. Snapshots provide a recoverable backup.**

# 16. Why EC2 Has a Public IP

The EC2 instance is the application/jump server and may have a public IP for administration during the lab.

That does not mean the RDS database needs public access.

```text
EC2:
Publicly reachable application/admin layer

RDS:
Private database layer
```

# 19. If Connection Times Out

Check:

```text
RDS
 |
 +-- Public access = No
 |
 +-- Port = 5432
 |
 +-- SG allows EC2 SG
 |
 +-- Correct VPC
```

Do not make the database public simply to bypass a configuration problem.

# 23. Interview Questions

### Q1. Why is RDS not public?

Because the application server can access it privately, reducing unnecessary exposure of the database.

### Q2. What port does PostgreSQL use?

```text
TCP 5432
```

### Q3. How does RDS know which application can connect?

Its security group allows PostgreSQL traffic from the EC2 security group.

### Q4. Why use a security group ID instead of `0.0.0.0/0`?

It restricts database access to the intended application security group rather than the entire internet.

### Q5. What does Multi-AZ provide?

A managed standby database in another Availability Zone for improved availability and failover.

### Q6. Does the application connect directly to the standby?

No. The application uses the RDS endpoint.

### Q7. What is a manual snapshot?

A manually created database backup/recovery point.

### Q8. Is Multi-AZ the same as a snapshot?

No.

```text
Multi-AZ → availability/failover
Snapshot → backup/recovery
```

### Q9. Why use RDS instead of installing PostgreSQL on EC2?

RDS is a managed database service, reducing the database infrastructure administration required by the application team.

### Q10. What is the architecture's most important security rule?

Only the intended application security group should be allowed to reach RDS PostgreSQL on TCP 5432.

# 24. Memory Rule

> **EC2 runs the application. RDS runs PostgreSQL. Port 5432 carries the database traffic. The RDS security group trusts the EC2 security group. Multi-AZ provides a standby. Snapshots provide recovery.**
