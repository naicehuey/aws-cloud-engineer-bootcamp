# IAM Notes

## AWS IAM

IAM stands for Identity and Access Management.

AWS IAM is used to control who can access AWS resources and what actions they are allowed to perform.

---

## IAM User

An IAM user represents an individual identity within an AWS account.

A user can have credentials and permissions that allow them to interact with AWS.

Example:

```text
developer-user
